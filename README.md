## 🎯 What is Web3NG?

Global Web3 updates (such as MoonPay PayBox, Galxe quests, AI DePIN nodes, and testnet faucets) often fail for Nigerian users due to silent IP geo-blocking, strict non-NIN KYC requirements, high gas costs on L1, and phishing drainers. 

**Web3NG** eliminates wasted time and gas by verifying eligibility, providing Nigeria-tested execution workarounds, and offering instant Naira (NGN) bank offramp calculators.

---

## 🔥 Key Features

- **⚡ Nigeria-Verified Drop Radar**: Real-time feed of 18+ active Web3 projects, DePIN bandwidth nodes, AI compute nodes, testnets, and exchange quest hubs.
- **🔍 "Am I Eligible?" Link Inspector**: Instant 5-point link analyzer checking Nigeria IP routing, NIN identity verification support, network gas efficiency, and phishing drainer safety.
- **📡 Telco & Web3 DNS Optimizer**: Access status breakdown for MTN, Airtel, Glo, & 9mobile users with 1-click `1.1.1.1` DNS setup to eliminate Cloudflare captcha loops.
- **💰 Naira (NGN) Micro-Offramp Calculator**: Estimate net NGN bank deposits across Yellow Card, Quidax, Bitmama, and Binance P2P.
- **🛡️ Anti-Phishing Scam Shield**: Community-maintained index of flagged fake claim sites and malicious contract drainers.
- **🔄 Live Auto-Sync Engine**: Background Python script (`scripts/fetch_drops.py`) and React auto-refresh timer to dynamically pull emerging Web3 opportunities.
